Консольное приложение для анализа оценок студентов, написанное на языке Dart

## Запуск

1. Клонировать репозиторий: `git clone https://github.com/cocos812/Dart1_Lab1.git` — скачивает копию репозитория с GitHub на компьютер    
2. Перейти в папку: `cd Dart_Lab1` — переходим внутрь папки
3. Установить зависимости: `dart pub get` — скачивает все пакеты, которые нужны проекту
4. Запустить: `dart run` — запустится файл, `void main()` — стандартная точка входа любой Dart-программы

## Изучили

1. Переменные и базовые типы — `int`, `double`, `String`, `bool`; явное указание типа и `var`
2. Null Safety — тип `String?` разрешает `null`, операторы `?.` и `??` защищают от ошибок
3. `final` и `const` — неизменяемые переменные; `final` во время выполнения, `const` во время компиляции
4. Функции — обычные, стрелочные `=>`, именованные параметры `{required ...}`, необязательные позиционные `[...]`
5. Коллекции — `List`, `Map`, `Set` и методы `map()`, `where()`, `forEach()` с анонимными функциями
6. Управляющие конструкции — `if/else`, `for`, `for-in`, `while`, `switch/case`
7. Консольное приложение — анализатор оценок: среднее, максимум, минимум, текстовая оценка, общая статистика

## Ответы на вопросы

1. Статическая типизация проверяет типы на этапе компиляции, а не в рантайме. Практическое преимущество — ошибки типов ловятся до запуска программы, код предсказуемее и проще рефакторится.

2. `String?` — nullable-тип: переменная может быть `null`. `String` — не-nullable: гарантированно строка. `String?` требует проверки перед вызовом методов, `String` — нет.

3. `final` — гарантия на уровне компилятора: повторное присваивание вызовет ошибку. В Python это лишь устная договорённость, которую никто не проверяет.

4. Именованный параметр передаётся по имени: `describePet(name: 'Барсик', age: 3)`. Позиционный — по порядку: `greet('Артём')`. `required` делает параметр обязательным. Пример: `describePet(name: 'Шарик', species: 'пёс')` — порядок не важен.
